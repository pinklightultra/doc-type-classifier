Data Exchange FAQ

Common questions about the outbound data exchange feed.

How often does the feed run?

Once a day, on a schedule you set separately for each environment.

What happens when a file is rejected?

The file is retried twice, then listed in the exchange log for a person to look at. Nothing is deleted.

Can two feeds share one destination?

Yes. Give each feed its own filename prefix so the destination folder stays readable.

Where do I see the last run?

Open the exchange log and sort by run time. The newest run is at the top.
