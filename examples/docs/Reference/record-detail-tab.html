Record Detail Tab

The Record Detail tab shows the stored values for one record. It is read-only for every role except the record owner.

FieldDescription
ReferenceGenerated identifier for the record. Not editable.
StatusCurrent state: Draft, Active or Closed.
OwnerTeam or person responsible for the next action.
OpenedDate the record was first saved.

Notes

Values here come from the record itself. A change made anywhere else shows up only after the tab is refreshed.
