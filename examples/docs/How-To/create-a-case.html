Create a Case

Create a case when a request has to be tracked through to a resolution. Cases are visible to everyone on the assigned queue.

Before you begin

  • You need the case author role.
  • Have the requester's reference number to hand.

Steps

  1. Go to Work > Cases.
  2. Select New case. The blank case form opens.
  3. Enter a one-line summary and pick a queue.
  4. Select Save. The case opens with a generated reference.

Result

The case appears at the bottom of the queue you picked, and the requester gets a confirmation notice with the reference on it.
