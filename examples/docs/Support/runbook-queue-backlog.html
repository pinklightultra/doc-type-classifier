Runbook: Queue Backlog

Internal runbook. Use it when a work queue stops draining and items pile up past the agreed depth.

Trigger: queue depth above the threshold for two hours

The depth alert fires on the scheduled check, not in real time, so confirm the current depth before acting.

First checks

  • Confirm the queue processor is running.
  • Check whether one oversized batch is blocking everything behind it.

Escalation

If depth is still rising after the first checks, page the on-call rota and record the start time in the incident channel.
